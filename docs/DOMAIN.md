# DOMAIN.md - ビジネスロジック & ドメインルール

## 1. テーマ状態管理ルール
- **状態定義**: `theme` ＝ `'light'` | `'dark'` | `'system'`
- **永続化**: ユーザーが明示的に指定したテーマは `localStorage` に保存する。
- **OS同期**: 初期化時または未設定時は OS の表示設定（`prefers-color-scheme: dark`）を優先適用する。

## 2. アニメーション発火ルール
- **テーマ切替アニメーション**: 色変更時のトランジション（Transition）は `200ms〜300ms` に抑え、画面のちらつきを防止する。
- **インタラクション発火**: モーダル表示やホバー時の移動は `ease-out` カーブを標準とする。

## 1. ゲームドメインルール
- **フィールドサイズ**: 横10マス × 縦20マス。
- **ミノの種類**: I, J, L, O, S, T, Z（7種類）。
- **スコア計算**: 1ライン消去: 100pt, 2ライン: 300pt, 3ライン: 500pt, 4ライン（テトリス）: 800pt。

## 2. データ構造仕様 (localStorage)
- **保存キー**: `tetris_game_state`
- **保存オブジェクト例**:
  ```json
  {
    "highScore": 12500,
    "lastSavedState": {
      "board": [[0,...]],
      "currentScore": 3200,
      "level": 3
    }
  }
  ```
