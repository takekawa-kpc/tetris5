# TESTING.md - テスト戦略 & 品質基準

## 1. テスト方針
- **テストツール**: Playwright
- **使用言語**: TypeScript (`*.spec.ts`)

## 2. 主要テストシナリオ
### ① ダークモード切替検証
- テーマ切替ボタン押下時に `<html>` 要素へ `dark` クラスが付与されるか。
- `localStorage` に適切なテーマ設定値が保存されるか。

### ② 表示 & アニメーション検証
- 主要コンポーネントが崩れなく表示されるか。
- アニメーション動作後に要素が正しく表示状態に遷移するか。
